# Nura Chain

**Nura Chain** is an open-source, EVM-compatible blockchain designed for fast, scalable, and developer-friendly decentralized applications.

Nura Chain brings the **Ethereum Virtual Machine (EVM)** ecosystem to a high-performance blockchain built with the **Cosmos SDK**, enabling developers to deploy Solidity smart contracts and use familiar Ethereum tooling while benefiting from the Cosmos ecosystem.

## What is Nura Chain?

Nura Chain is an **EVM-compatible Layer 1 blockchain** focused on providing a familiar Ethereum development experience with the flexibility of the Cosmos ecosystem.

Developers can use **Solidity, Ethereum JSON-RPC, MetaMask, EVM wallets, Blockscout, and standard Ethereum developer tools** to build and interact with applications on Nura Chain.

The network is designed as an open infrastructure layer for decentralized applications, smart contracts, tokens, wallets, DeFi, payments, and Web3 applications.

## Key Features

- **EVM compatible** — Deploy and interact with Solidity smart contracts using familiar Ethereum tooling.
- **Ethereum JSON-RPC** — Connect applications and wallets using standard EVM RPC interfaces.
- **Cosmos SDK based** — Built on the modular Cosmos blockchain stack.
- **Solidity smart contracts** — Use the existing Ethereum developer ecosystem.
- **EVM wallets** — Compatible with common EVM wallet workflows such as MetaMask and other Web3 wallets.
- **ERC-20 tokens** — Create and interact with Ethereum-compatible tokens on Nura Chain.
- **Blockscout explorer** — Explore blocks, transactions, addresses, tokens, and smart contracts.
- **Open source** — Core Nura Chain software and ecosystem components are developed openly on GitHub.
